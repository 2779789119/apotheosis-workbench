# 神化工作台 / Apotheosis Workbench

面向 Minecraft **1.20.1 Forge（47.x）** + **神化 Apotheosis 7.x** 的词条管理工具。
在游戏内一个界面里浏览、添加、删除、禁用词条，并调整每条词条属于哪些品阶。

## 安装

- Minecraft 1.20.1
- Forge 47.x
- Apotheosis 7.x（依赖 Placebo、AttributesLib）
- 本模组放进 `mods` 即可，客户端与服务端都要装（单机由内置服务端加载）

## 打开方式

```
/apothwb          # 打开工作台（需要 OP 权限等级 2）
/awb              # 同上，简写
/apothwb save     # 直接保存并重载（控制台也可用）
/apothwb refresh  # 重新扫描数据包
```

## 界面说明

| 区域 | 说明 |
| --- | --- |
| 顶栏 | 词条统计、「保存并重载」、「刷新」、「关闭」 |
| 左栏 | 全部 / 已修改 / 已禁用 / 已删除 / 自定义 五种筛选；下方是品阶筛选 |
| 中间 | 词条列表，显示名称、类型、效果摘要、所属品阶色点、状态标记；滚轮翻页 |
| 右栏 | 选中词条的详情与操作 |

界面上几乎所有可点的地方都有悬浮提示：列表行、品阶色块、各个按钮、数值输入框、筛选按钮，鼠标停一下就能看到说明。

词条的**效果描述**会显示在列表悬浮提示和右栏详情里。注意描述不是数据包里的文本，而是神化代码按 `values[品阶]` 的数值现算的，所以：
- 显示的是该词条「最高已启用品阶」的效果；
- 新建的自定义词条、或被禁用/屏蔽的词条，在「保存并重载」之前没有描述（游戏内还没有这条词条）。

打开界面时单人游戏会**暂停世界**（原版机制），所以编辑期间不会被怪打断；多人服务器上不会暂停（服务端照常跑）。暂停期间的重载会挂起，关掉界面后自动补上。

界面上品阶、词条类型、适用部位都是中文（`普通 / 罕见 / 珍贵 / 史诗 / 神话 / 远古 / 神器 / 传家宝 / 秘传`、`属性 / 药水效果 / 伤害减免 …`、`剑 / 弓 / 头盔 / 胸甲 …`），英文原名放在悬浮提示里。品阶中文名优先读神化自己的语言文件，所以换语言或以后的版本加了新品阶都能自动跟上。

## 批量与高级操作

- 列表行左侧有复选框：**Shift 连选**、**Ctrl 切换**；勾选后右栏切成批量面板，可批量启用 / 禁用 / 删除 / 加入或移出品阶
- 详情里「改部位」可以改这条词条能出现在哪些物品上（只对本身有部位字段的类型开放）
- 「拷 / 贴」：把整条词条 JSON 复制到剪贴板，用外部编辑器改完再贴回来，改属性 ID、运算方式、冷却这类界面没覆盖的字段就靠它
- 效果描述会跟着「编辑品阶」切换显示

## 校验与兜底

- 保存前会校验 type、属性 id、效果 id、部位名、品阶键、数值格式，不合格直接拦下并报原因
- 重载后会核对哪些词条没注册成功，列表里标红加 `!`，聊天里也会点名（这种情况通常就是数据填错了）
- 屏蔽 / 删除 / 恢复原样都要连点两次确认
- 每次写状态前会把上一版存成 `<存档>/apoth_workbench/state.json.bak`

右栏操作：

- **品阶色块**：点一下切换该词条是否属于这个品阶（这就是「调整品阶」）
- **编辑品阶**：循环切换要编辑数值的品阶；下面三个格子是「保底 / 档数 / 每档加」，右边会实时显示这条词条能刷到的范围（例如 `能刷到 0.3 ~ 0.7`）
- **保存数值**：把三个数值写入当前编辑的品阶
- **同步全部**：把当前数值套用到该词条所有品阶
- **禁用/启用**：保留数据但让词条不再加载（不再出现在战利品里）
- **屏蔽词条**（内置词条）/ **删除词条**（自定义词条）：丢弃编辑并把词条从游戏中移除
- **恢复原样**：还原成词条出厂数据
- **复制为新词条**：以当前词条为模板新建一条（可改 ID、品阶、部位）

## 新建词条

四种方式，覆盖从"改个数值"到"完全自己写"：

| 方式 | 适合场景 |
| --- | --- |
| **复制** | 已有同类词条，只改 ID / 品阶 / 数值 / 部位（最快） |
| **属性** | 从零建纯属性词条（加最大生命、移速、护甲…） |
| **药水** | 从零建"什么时候给什么效果"（自己受伤/攻击命中 → 施加效果） |
| **粘贴 JSON** | 从剪贴板读一条完整 JSON 直接建，做顺劈/庆典/处决这类 special 词条 |

例：做一条「攻击命中时给敌人缓慢」的词条 —— 药水模板 + 效果 `minecraft:slowness` + 触发"攻击命中时" + 部位 `sword` + 品阶勾史诗/神话即可。

### 自建词条的名字

新建界面的「名称」框直接填就行 —— 名字存在存档的工作台状态里，客户端会把它注入语言表，所以**物品 tooltip 里立刻显示中文名**，不需要资源包，也不用改 lang 文件。已存在的词条可以在详情里点「改名」，留空则恢复原名。资源重载（F3+T）或切换语言后会自动重新注入。

如果希望名字跟着整合包分发（换存档也生效），再用下面的资源包 / KubeJS 方案：

1. 用 KubeJS 客户端脚本补（推荐，不用发包）：

```js
ClientEvents.lang('zh_cn', event => {
  event.add('affix.apoth_workbench:custom/frost', '霜冻')
  event.add('affix.apoth_workbench:custom/frost.suffix', '· 霜冻')
  event.add('affix.apoth_workbench:custom/frost.desc', '攻击有 %s%% 概率使敌人缓慢')
})
```

2. 做成一个资源包放在 `resourcepacks/` 里，写 `assets/apoth_workbench/lang/zh_cn.json`
3. 直接用一个已有的词条 ID 覆盖（不推荐，容易和别人的数据包冲突）

### 各模板要填什么

- **复制**：只需改 ID，其它沿用原词条
- **属性**：属性 ID（如 `minecraft:generic.max_health`）+ 运算方式 + 部位 + 品阶与数值
- **药水**：效果 ID（如 `minecraft:speed`）+ 触发时机 + 部位 + 品阶与持续时间参数

属性 / 效果 ID 不用手打，点输入框右边的「选…」会弹出可搜索列表（列出游戏里所有已注册的属性和药水效果，中文名 + id 对照）。
- **粘贴 JSON**：只需要一个合法 ID，内容全部取自剪贴板

部位可写多个，用逗号分隔：`sword,bow,helmet,chestplate,leggings,boots,shield,trident,pickaxe,shovel,crossbow,heavy_weapon`。

## 导出为 KubeJS 脚本

顶栏「导出脚本」或 `/apothwb export`，会把当前改动写成：

```js
// 由「神化工作台」Apotheosis Workbench 自动生成
ServerEvents.highPriorityData(event => {

	// apotheosis:armor/attribute/aquatic · 已禁用
	event.addJson('apotheosis:affixes/armor/attribute/aquatic', {
  "conditions": [
    {
      "type": "forge:false"
    }
  ]
});
});
```

- 装了 KubeJS：直接写到 `kubejs/server_scripts/apoth_workbench_affixes.js`，`/reload` 后生效
- 没装 KubeJS：写到 `apoth_workbench_export/apoth_workbench_affixes.js`，需要自己拷进整合包的 `kubejs/server_scripts`
- 这份脚本和「保存并重载」生成的覆盖数据包是**两套等效做法**，用脚本时请把工作台的改动清空（逐条「恢复原样」或删掉 `<存档>/datapacks/apoth_workbench/`），别让两套覆盖同时生效
- 想跟整合包一起分发、进版本管理，用脚本；只想本存档生效，用工作台自带的数据包

## 改动是怎么生效的

- 神化的词条与品阶都是**数据包驱动**的，本模组不改内存注册表，而是生成一个覆盖数据包：
  - `<存档>/datapacks/apoth_workbench/`：生成的覆盖文件（禁用的词条写 `{"conditions":[{"type":"forge:false"}]}`）
  - `<存档>/apoth_workbench/state.json`：工作台自己的编辑状态（记录原始数据、当前数据、被移除品阶的数值）
- 每次操作都会立刻写到磁盘（不会丢），但要游戏内生效需要点「保存并重载」或执行 `/apothwb save`。
- 开服时如果检测到覆盖数据包还没启用，模组会自动启用并重载一次。
- 把 `<存档>/datapacks/apoth_workbench/` 删掉，或在界面里把所有改动「恢复原样」，即可完全回到原版神化数据。

## 已知限制

- `values` 之外的字段（属性 ID、运算方式、触发时机等）不能在界面里改，需要复制现有词条或手改生成出来的 JSON。
- 药水类的品阶数值是复合结构（`duration` / `amplifier` / `cooldown`），界面里只支持开关品阶，不支持改数值。
- 少数没有 `values` 字段的词条类型（如 `durable`）本身不受品阶限制，只能整体禁用/删除。
- 移除某品阶后，已经带这条词条且属于该品阶的旧物品会失去该词条效果（神化自身的 `canApplyTo` 会过滤掉）。
- 移除品阶过多时，神化会在日志里提示「Insufficient number of affixes to satisfy the loot rules」，属于正常警告。
